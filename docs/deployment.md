# 板子库部署方案（本地 + 云端）

本仓库以 NOI 板子库为核心内容，考虑两种典型使用场景：

## 本地方案（单机/离线）
- **目标**：在无网络环境下快速检索、复制模板。
- **形态**：本地 Git 仓库 + Markdown 索引 + 可选脚本生成索引。
- **要点**：
  - 保持目录结构简洁，方便 `ripgrep` 搜索。
  - 将常用模板做成 `snippets` 或编辑器片段（可选）。
  - 提供离线索引（例如 `docs/index.md`），每个模板标注“适用场景/复杂度”。

## 云端方案（同步/共享）
- **目标**：跨设备同步、团队共享、历史版本回溯。
- **形态**：Git 远端托管（GitHub/GitLab）+ 可选文档站点。
- **要点**：
  - 以 `main` 分支作为稳定版，使用 tag 标记重要版本。
  - 维护变更日志，保证模板更新可追踪。
  - 若需要在线阅读，可使用静态站点生成（如 MkDocs/Docsify）。

## 双端协同建议
- 本地以 Git 作为唯一数据源。
- 云端为远程镜像与协作入口。
- 建议保留“本地模板路径 + 云端索引路径”两份入口文档。
