# NOI 板子库建设路线

该路线参考 oi-wiki 的知识体系，按常见 NOI 题型优先级组织。

## Phase 1（核心必备）
### 数据结构
- 并查集
- 树状数组
- 线段树（含懒标记）

### 图论
- BFS / DFS
- 最短路（Dijkstra / SPFA / 0-1 BFS）
- 最小生成树（Kruskal / Prim）
- 拓扑排序

### 数学
- 快速幂
- 扩展欧几里得
- 逆元与组合数

### 字符串
- KMP
- 哈希

### 常用技巧
- 二分
- 前缀和 / 差分
- 双指针

## Phase 2（中级扩展）
### 图论
- LCA
- Tarjan（SCC / 割点 / 桥）
- 网络流（Dinic）

### 数学
- 线性筛
- 质因数分解
- CRT

### 字符串
- Trie
- AC 自动机

### 动态规划
- 常见区间 DP / 树形 DP 模板

## Phase 3（高级/竞赛加分）
### 图论
- 最小费用最大流
- 最短路优化技巧

### 数学
- NTT / FFT
- 矩阵快速幂

### 计算几何
- 叉积 / 线段相交
- 凸包

## 模板文件约定
- 文件命名：`algo_name.cpp` 或 `algo_name.hpp`
- 文件头注释必须包含：
  - 适用场景
  - 复杂度
  - 注意事项
