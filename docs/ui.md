# 本地与云端 UI 规划

本地与云端 UI 保持一致：均以 Markdown 索引作为入口，云端可直接渲染为静态站点。

## 共同的 UI 入口
- `docs/index.md` 作为统一索引页。
- 每个算法小模块在 `templates/<分类>/<算法名>/README.md` 提供三段式内容：
  1) 算法名称  
  2) 例题（可选）  
  3) 用户板子（每个用户的模板/专栏）

## 本地体验
- 使用编辑器浏览 `docs/index.md` 并通过目录跳转。
- `rg` 快速搜索算法名与用户板子。

## 云端体验
- 直接在 Git 托管平台浏览 Markdown（默认渲染）。
- 若需要更好的阅读体验，可使用静态站点生成器渲染同样的结构。
